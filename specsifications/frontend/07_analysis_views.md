==================================================
SPECIFICATION 07: ANALYSIS VIEWS (MODERNIZER & CLOUD)
==================================================

1. MODULE OBJECTIVE:
   Build the dashboard visualization components for the Next.js frontend to render the complex JSON artifacts generated by the backend engines. This encompasses the Modernizer Tab (for microservice blueprints) and the Cloud Optimizer Tab (for infrastructure metrics and fixes).

2. MODERNIZER DASHBOARD (Microservice Blueprints):

- **Component Layout:** Create a UI component that iterates over the `microservices` JSON array from the backend. Render each proposed microservice as an interactive, expandable card.
- **Data Rendering:** Each card must prominently display the `service_name`, `description`, and a list of `original_files_referenced`.
- **Code Visualization:** Integrate `react-syntax-highlighter` to render the auto-generated OpenAPI specifications and structural code snippets.
  - Utilize a Prism or highlight.js theme that matches your Tailwind color palette.
  - Include a "Copy to Clipboard" button inside the code block headers for immediate developer utility.
- **State Handling:** Use the `"use client"` directive at the top of the file, as these cards require local state interactivity (expand/collapse toggles and clipboard APIs).

3. CLOUD OPTIMIZER DASHBOARD (Infrastructure Scans):

- **Component Layout:** Implement a responsive Tailwind CSS grid to display the infrastructure scan results.
- **Metric Cards:** At the top of the dashboard, render aggregate status cards summarizing the total Security, Cost, and Performance issues identified.
- **Vulnerability Feed:** Below the metrics, display a detailed list of specific findings.
  - **Severity Highlighting:** High-severity vulnerabilities MUST be highlighted with a red border and background tint (e.g., `border-red-500`, `bg-red-50/10`). Medium severity should use yellow (`border-yellow-500`), and Low severity should use blue (`border-blue-500`).
  - **Actionable Fixes:** For each finding, display the `issue_type` and `description`. Use `react-syntax-highlighter` to present the "Suggested Fix" code blocks so users can immediately see and copy the optimized infrastructure code.

4. INTEGRATION CONSTRAINTS:

- Both dashboard tabs must retrieve their respective JSON data arrays from the global Zustand `job_status` artifacts payload built in Spec 06.
- **Graceful Degradation:** If the backend JSON is empty or the job is still marked as `PROCESSING`, display a custom Tailwind CSS pulse skeleton loader instead of a blank screen or broken layout.
